ParticleQC · 범용 입자 AI 품질검사 (NEXT CELL)
==============================================
만든 사람: NEXT CELL · 순천제일대학교 에너지소재화공과 · 윤성빈(팀장), 김태욱, 공진우, 허동현
버전 v1.0.3 (2026-10-29) · © 2026 NEXT CELL · MIT 라이선스 (LICENSE 파일)
흑연 전용 프로그램(GraphiteQC)과 달리, 재료·배율·현미경이 달라도 쓸 수 있게 만든 프로그램입니다.
스케일(µm/px)과 입자 크기만 알려 주고, 입자를 normal / abnormal / exclude 로 나눠 주면 AI를 학습시켜 검사합니다.

[설치·실행]  GraphiteQC 와 같습니다.
1. 이 폴더(ParticleQC)를 원하는 곳에 둔 뒤 "1_처음_설치.bat" 더블클릭 (5~10분, 인터넷 필요).
   Python 3.12 가 없으면 자동으로 설치할지 물어봅니다. Y 를 누르면 python.org 에서 받아 설치합니다.
   (다른 Python 과 PATH 는 그대로. 자동 설치가 안 되면 https://www.python.org/downloads/release/python-31210/
    에서 Python 3.12.10 을 직접 설치하고, 설치할 때 "Add python.exe to PATH" 체크)
2. 이후에는 바탕화면 "입자 품질검사 ParticleQC" 아이콘 더블클릭. 인터넷 없이 동작합니다.
   (GraphiteQC 와 동시에 켜도 됩니다. 주소가 다릅니다: 127.0.0.1:7861)

[쓰는 순서]  재료마다 프로젝트 폴더 하나를 만듭니다 (예: 문서\ParticleQC\NCM양극재).
① 설정·미리보기
   - 사진 1장을 올리고, 스케일 바 길이(µm)를 넣은 뒤 "스케일 바 자동 측정" → µm/px 가 계산됩니다.
     (사진 아래 검은 정보 바에 흰 스케일 바가 있는 SEM 사진에서 동작. 안 되면 ImageJ 등으로 바의 픽셀 길이를 재서 µm÷px 를 직접 입력)
   - 예상 입자 크기(D50, µm)를 넣습니다. 프로그램이 내부에서 입자가 약 130픽셀 크기가 되도록 사진을 맞추기 때문에
     배율이 달라도 같은 조건으로 분석됩니다. 측정 D50이 예상과 많이 다르면 경고가 뜨니 그 값으로 바꾸고 다시 미리보기.
   - 입자가 배경보다 어두운 사진(광학현미경 등)은 "입자가 배경보다 밝음" 체크를 해제합니다.
   - 미리보기에서 초록 윤곽이 입자에 잘 맞으면 "설정 저장". 입자를 놓치면 밝기 문턱을 낮추고, 배경까지 잡으면 높입니다.
   - 합격 기준(abnormal 최대 %, 필요하면 크기 범위)도 여기서 저장합니다.
② 라벨링 준비
   - 사진 여러 장을 올리고 시료 이름(예: 정상 / 손상)을 적은 뒤 "입자 잘라내기".
     → 프로젝트\labeling\_crops 에 입자 그림, labeling\sheets 에 한눈에 보는 표가 생깁니다.
   - 탐색기에서 _crops 의 그림을 normal / abnormal / exclude 폴더로 옮깁니다.
     normal = 정상, abnormal = 결함(깨짐·균열·박리·오염 등 그 재료의 불량 정의), exclude = 겹침·흐림·입자 아님·판단 불가.
     exclude 를 넣어야 프로그램이 "판정 불가"를 배웁니다.
   - 권장: abnormal 100개 이상, 전체 1,000개 이상 (사진 10~20장).
③ 학습
   - "학습 시작" → 5~10분. 사진 단위 교차검증으로 abnormal 정밀도·재현율, 시료별 비율(AI vs 사람)이 나옵니다.
   - 결과가 나쁘면 라벨을 더 모으거나(특히 abnormal), 라벨 기준을 일관되게 다시 봅니다.
④ 검사
   - 같은 조건으로 찍은 사진 10장 이상을 올리면 합산 판정 + 95% 신뢰구간, 사진별 표, 그래프가 나옵니다.
   - 신뢰구간이 기준에 걸치면 "판정 보류"와 함께 몇 장을 더 찍을지 알려 줍니다.
   - 입자를 제대로 못 찾은 사진(주름·오염)은 자동으로 빼고 알려 줍니다.

[한계]
- 입자 찾기는 "배경보다 밝은(또는 어두운) 덩어리를 윤곽으로 나누는" 방식이라, 입자끼리 겹쳐 쌓인 사진이나 배경이 울퉁불퉁한 사진은 안 됩니다.
- 입자가 수십 픽셀도 안 되게 작게 찍힌 사진은 배율을 올려 다시 찍어야 합니다 (입자 지름이 원본에서 60픽셀 이상 권장).
- 결함의 정의는 재료마다 사람이 라벨로 정해 주는 것이고, 합격 기준(abnormal 몇 %)도 그 제품의 정상 시료로 잡아야 합니다.
- 흑연 외 재료로는 아직 검증하지 않았습니다. 흑연 데이터를 normal/abnormal/exclude 로 바꿔 넣어 동작을 확인했습니다.

[문제가 생기면]
검은 창에 나온 메시지를 캡처해서 보내주세요.

[윤곽 다듬기 · 겹친 입자]
  - 입자 옆 부스러기가 가늘게 이어진 '꼬리'와, 어둡고 흐릿한 테이프 주름이 붙어 번진 '날개'는 자동으로 잘라 냅니다.
  - 두 입자가 한 윤곽에 묶인 8자·땅콩 모양이나, 크고 한쪽이 깊게 파인 입자는 normal 로 나와도 '붙은 입자(파랑)'로 뺍니다.
    위에 얹혀 홈이 없는 겹침은 exclude 로 라벨링해 학습시키면 AI 가 '판정 불가'로 거르게 됩니다.

[④ 검사 — 결과 고치기 (입자를 클릭해서 판정 바꾸기)]
  1. 검사 시작 후 아래 '결과 고치기'에서 고칠 사진을 고릅니다.
  2. '입자를 클릭하면 이렇게 바꿉니다'에서 바꿀 판정을 고릅니다: normal(초록)·abnormal(빨강) · 붙은·겹친 입자로 빼기(파랑) ·
     판정 불가로 빼기(회색) · 사람이 뺌(흰 ×) · 자동 판정으로 되돌리기
  3. 입자의 윤곽 안쪽을 클릭하면 그 판정으로 바뀌고 가운데에 흰 점이 찍힙니다. 어느 색이든 바꿀 수 있습니다.
     보라(입자 아님)를 정상·결함으로 고르면 입자로 넣어 크기와 모양을 잽니다.
     같은 판정을 고른 채 다시 누르면 자동 판정으로 돌아갑니다. '이 사진 고친 것 모두 취소'로 한꺼번에 되돌릴 수 있습니다.
  4. '고친 내용으로 다시 계산'을 누르면 판정·표·그래프가 고친 내용으로 바뀝니다.
     CSV 에는 judge(고친 판정) · judge_auto(자동 판정) · edited(사람이 바꿨는지)가 함께 남습니다.
